# PlanRepo v2 UI 디자인 시안

요구사항: [planrepo-requirements-v2.md](../planrepo-requirements-v2.md)

`index.html`을 브라우저에서 열면 됩니다. 빌드, 설치, 외부 폰트 및 라이브러리 없이 실행됩니다. 같은 폴더의 `styles.css`, `app.js`를 함께 보관하세요. 기존 `docs/ui-mockups` 시안은 변경하지 않았습니다.

## 디자인

밝은 문서 작업 공간, 저채도 초록색, 얇은 경계선으로 구성했습니다. 상단은 계정·저장소·브랜치, 왼쪽은 의사결정 및 의견 요청 대기열, 중앙은 마크다운 문서, 오른쪽은 문서 트리와 승인 현황입니다. 980px 이하에서는 문서 트리를, 680px 이하에서는 협의 대기열도 버튼으로 여는 패널로 전환합니다.

## 확인할 수 있는 흐름

1. 왼쪽 질문을 클릭하여 문서 내 해당 질문으로 이동합니다.
2. 선택지를 고르고 **선택 결과 일괄 반영**에서 변경 내용을 확인합니다. 반영 후 대기열과 원문에 결과가 반영됩니다.
3. **의견 요청**으로 문서 전체 또는 질문·섹션에 요청을 남깁니다. 문서 본문의 텍스트를 드래그하고 문서 상단 **의견 요청**을 누르면 선택 영역을 대상으로 지정합니다.
4. 의견 요청 대기열에서 요청을 열어 검토를 승인하거나 수정 의견을 남깁니다. 승인과 의사결정 반영은 별개입니다.
5. 문서 하단 토론에 일반 의견 또는 수정 요청을 남깁니다.
6. **수정 요청 모아보기**에서 코멘트를 선택하고 프롬프트를 생성·복사·다운로드합니다. 로컬 파일 환경에서 클립보드 접근이 제한되면 텍스트를 선택해 직접 복사할 수 있습니다.
7. 오른쪽에서 문서를 검색·이동하고, 내 승인을 기록합니다. 지정 검토자 3명 중 내 승인 1회만 추가할 수 있습니다.
8. **AI 인사이트**, **원문 보기**, 저장소·브랜치 팝업, 저장소 추가 등록, 프로젝트 설정을 확인합니다.

## 시안의 범위

- 모든 문서, 사용자, 대기열 및 상태는 예시입니다. 상태는 페이지 메모리에서만 유지되며 새로고침하면 초기화됩니다.
- 실제 GitHub/GHE 인증, 권한 검증, 저장소 등록·쓰기, LLM 호출 및 구문분석은 수행하지 않습니다. 브랜치를 바꿔도 공통 예시 문서를 표시합니다.
- Spec 폴더 설정은 경로 표시에 반영됩니다. 사용자 지정 질문·선택지 패턴은 추출 미리보기에 적용됩니다. 실제 파일 탐색과 파싱은 구현 범위 밖입니다.
- 승인 방식 설정은 화면 구성 제안입니다. 동작 시연은 지정 검토자 3명 전원 승인 정책으로 고정합니다.
- 타인에게 요청을 실제 전송하지 않습니다. 의견 요청은 시안 내 대기열에만 추가됩니다.
- 요구사항에서 미완성인 승인 이후 흐름은 요청 승인 상태 보관과 수정 코멘트의 별도 취합으로 표현했습니다.

키보드: `Tab`으로 제어 요소 이동, `Esc`로 팝업·모바일 패널 닫기, `/`로 문서 검색에 이동합니다.
